# Política de segurança

Este repositório é um **protótipo acadêmico** (Extensão III — UNINASSAU Olinda) e usa apenas dados sintéticos. Mesmo assim, levamos relatos de vulnerabilidade a sério.

## Como reportar

- **Não abra uma issue pública** para vulnerabilidades.
- Use o recurso **"Report a vulnerability"** na aba *Security* deste repositório (relato privado do GitHub).
- Descreva o problema, os passos para reproduzir e o impacto que você imagina.

## O que esperar

- Confirmação de recebimento em até 7 dias.
- Avaliação e, se for o caso, correção dentro do calendário acadêmico do projeto.
- Crédito a quem reportou, se desejar.

## Escopo

**No escopo:** o código deste repositório e a instância de demonstração mantida pela equipe.

**Fora do escopo:**
- ataques de negação de serviço;
- engenharia social contra a equipe;
- testes contra sistemas do Complexo Hospitalar da UPE ou de terceiros, que não fazem parte deste projeto.

Os controles de segurança do sistema estão descritos em [docs/security](docs/security/security-overview.md).
